# haseen.nvim

The Neovim setup that ships with [haseen](https://github.com/t1nk333r/haseen).

`init.lua` is the entry point; the configuration lives under `lua/`, with
filetype rules in `filetype.lua` and snippets in `snippets/`. haseen installs
it as `~/.config/nvim`; to use it elsewhere, clone it there:

```bash
git clone https://github.com/t1nk333r/haseen.nvim ~/.config/nvim
```
